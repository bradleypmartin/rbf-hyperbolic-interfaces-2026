# paper/ — the manuscript (epic #51)

The arXiv-ready write-up of Part 3, the seed stencils of
[`docs/stiff-features.md`](../docs/stiff-features.md) (issue #27). Scaffolded
in #52; the sections are drafted one sub-issue at a time (table below).
Follows the `paper/` pattern of the author's
[weil-positivity-lab](https://github.com/bradleypmartin/weil-positivity-lab),
[bolza-bending](https://github.com/bradleypmartin/bolza-bending) and
[dirichlet-bridge](https://github.com/bradleypmartin/dirichlet-bridge).

**Novelty is not claimed here** until the literature pass (#53) buckets the
claim in `LITERATURE.md`: cite, don't claim.

**Licensing.** `paper/` (`main.tex`, `references.bib`, `main.pdf`,
`figures/`) is [CC BY 4.0](LICENSE); the code in the rest of the repository
is MIT (see the root [README](../README.md)).

## Source-of-truth rule

`docs/stiff-features.md` stays canonical. The manuscript **quotes** it and
never becomes a second source of truth. Every number in `main.tex` traces to
a notes section or to the results cache of #54 (a `% TRACE` comment names
the source), and the assembly pass (#61) re-checks all of them.

## Files

| File | What it is |
|---|---|
| `main.tex` | The manuscript (single source file; amsart). Section stubs are visible in the PDF as *[Stub, …]* until the owning sub-issue replaces them. |
| `references.bib` | Bibliography. Every entry is flagged `TODO(verify)` until #53 checks it against a primary source and replaces the flag with a dated verification comment. No unverified citation ships. |
| `main.pdf` | The built PDF (committed deliverable). |
| `make_arxiv.py` | arXiv packaging (#62): stages `main.tex`, `main.bbl`, `references.bib` and the referenced figures into `arxiv/` and writes `arxiv.tar.gz`. |
| `figures/` | Generated by committed scripts from the results cache (#54), never hand-edited. |
| `LICENSE` | CC BY 4.0 for this directory. |

## Build (tectonic, primary)

```bash
cd paper/
tectonic main.tex                       # quick build
tectonic --keep-intermediates main.tex  # keeps main.bbl (needed for packaging)
```

Fallback (TeX Live / MiKTeX): `latexmk -pdf main.tex`.

**Pitfall (#52).** tectonic 0.16.9's BibTeX hangs forever, at full CPU
with no log, on an `amsalpha` label whose three-letter prefix contains a
braced accent in a single author's surname (`P{\'o}lya`). Write the accent
unbraced (`P\'olya`) in single-author entries. If a build spins for more
than a minute, bisect `references.bib`.

Intermediates (`.aux`, `.bbl`, `.log`, …) are gitignored; `main.pdf` is
committed on every change to `main.tex` or `references.bib`. The `\date` is
fixed by hand, never `\today`, so the committed PDF is reproducible from the
committed source.

## arXiv packaging (#62)

```bash
tectonic --keep-intermediates main.tex   # produces main.bbl
uv run python make_arxiv.py
```

arXiv builds from a flat source tree and does not run BibTeX, so the upload
carries the built `main.bbl`. `arxiv/` and `arxiv.tar.gz` are gitignored.
