# paper/ — the manuscript (epic #51)

The arXiv-ready write-up of Part 3, the seed stencils of
[`docs/stiff-features.md`](../docs/stiff-features.md) (issue #27). Scaffolded
in #52; the sections are drafted one sub-issue at a time (table below).
Follows the `paper/` pattern of the author's
[weil-positivity-lab](https://github.com/bradleypmartin/weil-positivity-lab),
[bolza-bending](https://github.com/bradleypmartin/bolza-bending) and
[dirichlet-bridge](https://github.com/bradleypmartin/dirichlet-bridge).

**Novelty is cited, not claimed.** The literature pass (#53, 2026-09-20)
bucketed the claim in the root [`LITERATURE.md`](../LITERATURE.md): every
ingredient is prior work (§1a there), the combination is "no prior instance
found" (§1b), and §6 there holds the only novelty wording the manuscript
may use.

**Licensing.** `paper/` (`main.tex`, `references.bib`, `main.pdf`,
`figures/`) is [CC BY 4.0](LICENSE); the code in the rest of the repository
is MIT (see the root [README](../README.md)).

## Source-of-truth rule

`docs/stiff-features.md` stays canonical. The manuscript **quotes** it and
never becomes a second source of truth. Every number in `main.tex` traces to
a notes section or to the results cache of #54 (a `% TRACE` comment names
the source). The assembly pass (#61) re-checked all of them, and the ones
the cache holds are asserted by `scripts/paper_numbers.py` (below).

## Build (tectonic, primary)

```bash
cd paper/
tectonic main.tex                       # quick build
tectonic --keep-intermediates main.tex  # keeps main.bbl (needed for packaging)
```

Fallback (TeX Live / MiKTeX): `latexmk -pdf main.tex`.

**Pitfall (#52, #61).** tectonic 0.16.9's BibTeX hangs forever, at full CPU
with no log, on an `amsalpha` label whose three-letter prefix contains a
braced accent in a single author's surname (`P{\'o}lya`), and the unbraced
form (`P\'olya`) avoids the hang but prints the label as `[P\'22]`. The two
single-author entries concerned carry the accented letter as UTF-8
(`Pólya`, `Mühlbach`), which labels as `[Pó22]` and `[Mü73]`. If a build
spins for more than a minute, bisect `references.bib`.

Intermediates (`.aux`, `.bbl`, `.log`, …) are gitignored; `main.pdf` is
committed on every change to `main.tex` or `references.bib`. The `\date` is
fixed by hand, never `\today`, so the committed PDF is reproducible from the
committed source.

## Figures and tables (#54)

Everything under `figures/` regenerates from committed sources:

```bash
uv run python scripts/paper_figures.py            # from data/: ~10 s
uv run python scripts/paper_figures.py --all      # + stills and spectra through the
                                                  # drivers (needs outputs/ caches): ~50 min,
                                                  # the two n = 2500 spectra most of it
uv run python scripts/paper_figures.py --check    # regenerate the cached set elsewhere,
                                                  # fail on any byte that differs
```

The convergence figures, the two seed-basis figures and every `tab_*.tex`
come from `data/` alone. The stills and the spectra need simulation state,
so `--all` runs the drivers in print style (`--style print --format pdf`)
against the reference and operator caches under `outputs/` and copies their
PDFs in. Print figures pin `SOURCE_DATE_EPOCH=0`, so a regenerated PDF is
byte-identical to the committed one; `--check` is the gate #61 scripts.

`data/` itself is refreshed by the drivers, from the caches under
`outputs/` (see CLAUDE.md for the runtimes):

```bash
uv run python scripts/wave1d_stiff.py --data-dir paper/data
uv run python scripts/wave2d_stiff.py --data-dir paper/data
uv run python scripts/wave2d_stiff.py --direction 1 2 --widths 0.0025 0.01 \
    --modes naive aware ablate --seed-floor --data-dir paper/data
uv run python scripts/wave2d_stiff.py --amplitude 0.02 --widths 0 0.0025 0.005 0.01 \
    --seed-floor --truncation --snapshot-width 0.005 --data-dir paper/data
uv run python scripts/wave2d_stiff.py --amplitude 0.02 --widths 0.005 --seed-rtol 1e-3 \
    --no-snapshot --data-dir paper/data
uv run python scripts/wave2d_stiff_eigenvalues.py --n 2500 --run --floor --data-dir paper/data
uv run python scripts/wave2d_stiff_eigenvalues.py --n 2500 --run --amplitude 0.02 \
    --data-dir paper/data
uv run python scripts/wave2d_stiff_eigenvalues.py --n 900 --widths 0.125 0.25 0.5 1 2 \
    --variants seeds hyper19 naive-hyper seeds30 naive19 --data-dir paper/data
```

Numbers in `main.tex` quote the notes and, where the notes round, the
cache's unrounded errors (each `% TRACE` comment says which). The
scripted half of the assembly check is

```bash
uv run python scripts/paper_numbers.py        # every cache-backed number the text quotes
```

which recomputes each ratio, rate and factor the manuscript states from
`data/` and fails on any that no longer rounds to the quoted value; add a
line to its table whenever the text quotes a new one. The notes' floor and
seed-floor rows of §5.4–5.6 carried hand-derived rates that differed from
the cache's by up to 0.2; #61 corrected the notes from the cache, so the
two agree.

## arXiv packaging (#62)

```bash
tectonic --keep-intermediates main.tex   # produces main.bbl
uv run python make_arxiv.py
```

arXiv builds from a flat source tree and does not run BibTeX, so the upload
carries the built `main.bbl`. `arxiv/` and `arxiv.tar.gz` are gitignored.
